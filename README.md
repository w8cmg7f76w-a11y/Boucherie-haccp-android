# Boucherie HACCP Android

Application Android personnelle créée à partir de **Boucherie HACCP v6.0 COMPLETE**.

## Télécharger l’APK

Ouvrir la section **Releases** du dépôt, puis télécharger `Boucherie-HACCP-v6.0.apk`.

## Données

Les données HACCP sont conservées localement sur l’appareil. Exporter une sauvegarde complète chaque semaine et avant chaque mise à jour.

## Compilation

GitHub Actions génère automatiquement un APK Android à chaque modification de la branche `main` et publie la version `v6.0`.
